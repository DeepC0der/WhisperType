Sub-70ms Transducer Speech Engine

WhisperType uses NVIDIA's Parakeet-TDT 0.6B quantized to 8-bit integers via sherpa-onnx. Unlike standard Whisper models that process audio in slow 30-second sliding chunks, Parakeet's Token-and-Duration Transducer outputs tokens asynchronously as you speak.

Universal Win32 Low-Level Keyboard Hook

WhisperType runs a native WH_KEYBOARD_LL hook on a dedicated Win32 message-pump thread. Unlike electron apps that drop hotkeys under heavy CPU load, WhisperType captures global hotkeys instantly even during AAA games or compile spikes, with instant Emergency Escape (Esc) cancellation.

Windows SmartScreen & Installation Guide

Why does Windows SmartScreen appear?
WhisperType is an open-source, non-profit community project built directly from source via GitHub Actions. Because code signing certificates cost upwards of $400/year, the binary is not yet digitally signed by an EV certificate, which triggers the standard Windows SmartScreen caution for newly compiled executables.

To launch WhisperType after downloading:

  1. When Windows displays "Windows protected your PC", click "More info".
  2. Click the "Run anyway" button at the bottom right.
  3. On first launch, WhisperType will guide you through granting microphone permissions in Windows Settings.
