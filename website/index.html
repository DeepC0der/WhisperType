Crucial Architectural Distinction: NVIDIA Parakeet TDT 0.6B Int8 is a specialized neural ASR (Automatic Speech Recognition) model, not a Large Language Model (LLM). Its sole purpose is converting spoken acoustic waveforms directly into verbatim text at sub-70ms latency (0.066x RTF) without conversational drift or hallucination loops. Both WhisperType Lite and WhisperType Standard use this exact same lightweight neural ASR engine.

In WhisperType Standard, you can optionally pair the Parakeet ASR engine with a local LLM (such as Meta Llama 3 or Qwen 2.5 running in LM Studio) to perform intelligent Pro AI text transformation: automatic grammar fixing, natural speech backtracking/self-correction, and structured Markdown formatting.

What are the key differences between WhisperType Lite and WhisperType Standard? ▾

WhisperType Lite is engineered specifically for everyday laptops and standard PCs. It is completely stripped of Local LLM / LM Studio and Pro Mode overhead so it runs effortlessly with a near-zero background footprint: just ~35 MB idle RAM, 2 CPU threads, pure NVIDIA Parakeet TDT 0.6B Int8 neural speech-to-text, and instant auto-unload during pauses.

WhisperType Standard is built for high-spec PCs and workstations capable of running local LLMs alongside speech recognition. It includes the full offline Parakeet ASR engine PLUS Pro AI Mode (triggered via Ctrl+Win or Mouse4) connected to local LLMs (via LM Studio / Llama 3 / Qwen) for speech backtracking/self-correction, grammar fixes, and Markdown note structuring.

Is NVIDIA Parakeet TDT an LLM? ▾

No. NVIDIA Parakeet TDT 0.6B is a specialized neural Automatic Speech Recognition (ASR) transducer model, not a Large Language Model. It does not generate text from prompts or converse; its only job is converting voice audio into written words with sub-70ms latency.

If you want AI rewriting, summarization, or note structuring, WhisperType Standard pairs the Parakeet ASR model with a local LLM (like Llama 3 or Qwen running offline in LM Studio) for Pro AI text transformation.

What is "Speech Backtracking and Self-Correction" in WhisperType Standard? ▾

When dictating naturally, people frequently change their mind mid-sentence: for example, "Send the report on Friday—wait, scratch that, make it Monday morning at 10am."

In WhisperType Standard's Pro AI Mode (triggered via Ctrl+Win or Mouse4), the connected local LLM recognizes self-correction phrasing, drops the discarded statement, and injects the final intended text directly into your active window: "Send the report on Monday morning at 10:00 AM."

How does WhisperType guarantee 100% air-gapped privacy? ▾

WhisperType operates with zero telemetry, zero analytics, zero external API keys, and zero cloud speech endpoints. When using WhisperType Standard's Pro AI Mode, requests are strictly routed to http://127.0.0.1:1234/v1 on your local machine. Every voice audio sample and transcribed character remains strictly on your local device.

Can I run WhisperType Lite on a standard laptop without a dedicated GPU? ▾

Yes, absolutely! WhisperType Lite is designed specifically for everyday laptops and PCs without dedicated GPUs. Its 8-bit quantized ONNX weights (Int8) execute via sherpa-onnx with AVX2 CPU acceleration, consuming only 2 CPU threads and ~35 MB idle RAM at an ultra-fast 0.066x Real-Time Factor.

Windows SmartScreen & Installation Guide

Why does Windows SmartScreen appear?
WhisperType is an open-source, non-profit community project built directly from source via GitHub Actions. Because code signing certificates cost upwards of $400/year, the binary is not yet digitally signed by an EV certificate, which triggers the standard Windows SmartScreen caution for newly compiled executables.

To launch WhisperType after downloading:

  1. When Windows displays "Windows protected your PC", click "More info".
  2. Click the "Run anyway" button at the bottom right.
  3. On first launch, WhisperType will guide you through granting microphone permissions in Windows Settings.
